# Scraping Jobstreet Vacancy Data
## Description
This project serves as a tutorial on how to scrape job vacancy data from Jobstreet using Python and BeautifulSoup. The extracted data can be used for job market analysis, salary trends, and demand forecasting.

## Features
✅ Extract job titles, company names, locations, salaries, and job descriptions

✅ Handle pagination to scrape multiple job listings

✅ Save scraped data to CSV for further analysis

## Tools Used
Python
BeautifulSoup (for web scraping)
Requests (to fetch webpage content)
Pandas (to store and process scraped data)
